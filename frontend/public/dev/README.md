# Development Mock Assets

These images are **development-only mock assets**, copied from the Git-tracked
prototype test files in `../../testphoto/`. They exist so the production
frontend can render local mock photo data before the Spring Boot API and
Cloudinary delivery exist.

- Not production photography storage.
- Not part of the future image pipeline (`PhotoImage` variants will come from Cloudinary).
- Do not add new or high-resolution photographs here.
